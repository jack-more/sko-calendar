How a file moves

Four steps, one owner each. If a file is stuck, it is stuck at a person, not in a folder.

01 · SHOOTRaw into Drive

Uploaded the same day it's shot, named correctly at upload. Unnamed files are not intake.

Noah, Roman
02 · ASSIGNHanded to an editor

Named in the content channel: which files, which editor, due date. Within 24 hours of upload.

Lance
03 · EDITRe-uploaded as _EDITED

Same folder, same name, status changed. Never a new folder, never a new name.

Erica, Xerky
04 · APPROVE_FINAL and scheduled

Posted in the content channel as final, then it enters a slot on this calendar.

Jack

Every file, every folder, no exceptions:

(subject)_(hook)_(format)_(seconds)_(status)

AousePOD_noticed_9x16_10s_FINAL

Status is one of RAW, EDITED, FINAL. It is the only part of the name that changes, and it changes in place — the file keeps its name through the whole pipeline so anyone can find it at any stage.

A twice-weekly touch base in the content channel: how many files are waiting on approval, and how many slots next week are still unfilled. Anyone can post it. Nobody waits to be asked.

Not decided yet

Four things this calendar is waiting on. Each one has an owner.

  • LIVE days and times — Billy. Every 17:00 slot promotes a LIVE, and paid spend points at it. Until the schedule is fixed, that slot runs a generic "we go live" cut, which is the weakest version of it.
  • Clipping accounts — Billy. GYMRATCUTS, LOOKSMAXGEMS and BIOHACKDEPT are claimed on TikTok and dark. Billy is posting the first ones himself; once that's tested, each one takes 3 a day off the same supply and the weekly number has to go up.
  • Creator pay — Jack and Billy. Two policies in circulation: 5% of every attributed sale, or $100 flat plus 15% affiliate. Creators can't be briefed for October until it's one number.
  • IG and YouTube — Jack. The same cuts cost nothing extra to post there. It's a per-week decision, and right now the answer is TikTok first.
