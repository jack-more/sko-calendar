# SKO Marketing Calendar

The team's content calendar: what gets posted where, on which day, with the files
anyone can download. Paid launches and budget changes show as a line at the foot of
the day; what's running now is listed under the month. The LIVE playbook tab is the
30-minute run of show.

Live at https://jack-more.github.io/sko-calendar/ (team passcode required).

Storage: `jackmorello.com/.netlify/functions/sko-cal` (repo jack-more/portfolio,
`netlify/functions/sko-cal.mjs`), Netlify Blobs. Local test mode with no server:
`python3 -m http.server 8123` then open `http://localhost:8123/?local=1`.
